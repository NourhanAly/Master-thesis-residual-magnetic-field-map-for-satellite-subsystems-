#CubeSat Residual Magnetic Field Modelling
This repository contains the MATLAB software developed for my master's thesis, "Modelling and Construction of Residual Magnetic Field Parameters Map for Satellite Subsystems", completed at Skoltech.

 #Overview
Magnetic cleanliness is an important requirement for CubeSats using magnetic attitude control. Electrical currents flowing through printed circuit boards (PCBs), power systems, and solar panels generate magnetic disturbances that can affect spacecraft attitude determination and control performance.
This project implements a MATLAB-based workflow for estimating these disturbances and evaluating the contribution of individual subsystems to the overall magnetic environment of a 3U CubeSat.

 
#Method
The software imports subsystem information from Altium design files together with electrical current data provided by the engineering team.
The workflow:
1. Reads component and subsystem information.
2. Calculates magnetic disturbances generated by PCB traces and solar panel currents.
3. Evaluates the contribution of individual subsystems to the overall magnetic field.
4. Generates residual magnetic field maps for different operating conditions.
5. Assesses how changes in operating mode and solar-panel orientation affect magnetic disturbances



#Engineering Outcome
The resulting software provides a repeatable method for analysing magnetic disturbances in CubeSat subsystems and identifying the dominant contributors to residual spacecraft magnetisation. The workflow enables engineers to evaluate design choices and operating conditions during spacecraft development.
